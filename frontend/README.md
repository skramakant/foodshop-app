# Food Shop — Standalone Frontend

A proper mobile-first frontend that calls the GAS backend as a JSON API.
No iframe, no media query issues — full CSS/Tailwind support.

## Project Structure

## Setup

### 1. Install dependencies
```bash
cd frontend
npm install
```

### 2. Set your GAS API URL
Edit `src/js/api.js` and replace `YOUR_GAS_WEB_APP_URL_HERE` with your
deployed GAS Web App URL.

### 3. Build CSS
```bash
npm run build        # one-time build
npm run watch        # watch mode during development
```

### 4. Copy JS to public/
Since we're not using a bundler yet, copy the JS files:
```bash
cp src/js/*.js public/js/
```

### 5. Run locally
```bash
npm run dev          # serves public/ at http://localhost:3000
```

### 6. Deploy to GitHub Pages
Push the `public/` folder contents to a GitHub Pages branch, or use
Netlify/Vercel by pointing the publish directory to `frontend/public/`.

## GAS Backend Changes

The `scripts/Main.gs` file now has a `doPost` handler that accepts JSON
requests from this frontend. Deploy a new version of your GAS project
after updating `Main.gs`.

## URL Structure

| URL | Description |
|-----|-------------|
| `https://your-site.com/` | Customer portal |
| `https://your-site.com/admin.html` | Admin portal |

## Adding Features

- **New API call**: Add to `src/js/api.js` + add action to `scripts/Main.gs` ACTION_MAP
- **New UI component**: Add CSS to `src/css/input.css` using Tailwind `@layer components`
- **New page**: Create `public/new-page.html` + `src/js/new-page.js`
